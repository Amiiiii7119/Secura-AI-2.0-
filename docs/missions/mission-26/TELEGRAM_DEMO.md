# Telegram Simulation Demo Guide

## 1. Features
- **Channel Directory:** Public channels and supergroups for governmental announcements and community updates.
- **Live Broadcasts:** Rich formatted broadcast messages with media and timestamps.
- **Interactive Reactions:** Emoji reaction dock allowing users to express sentiment (`👍`, `🔥`, `⚡`, `⚠️`).
- **Message Pinning:** Dynamic pin banner affixing critical announcements to the channel header.

## 2. Walkthrough Steps
1. Select the **Telegram** tab on the navigation bar.
2. Browse available channels (e.g., `#delhi-cyber-alerts`).
3. Click **Join Channel** to toggle membership and watch the subscriber count increment.
4. Click any reaction emoji below a broadcast post to observe the live counter increment.
5. Click the pin icon on an announcement to set or clear the channel pinned message.
